Install on Android

  1. Tap "Download for Android"The file Saathi.apk saves to your Downloads.
  2. Open the downloaded fileIf Android asks, allow "Install unknown apps" for Chrome. This is normal for apps outside the Play Store.
  3. Tap Install, then OpenSign up with your mobile number. You'll get a verification code.
  4. Set location to "Allow all the time"This lets sharing continue when the app is closed. Saathi shows a notification whenever it's sharing.
  5. Set battery to "Unrestricted"Settings → Apps → Saathi → Battery. Needed on Xiaomi, Vivo, Oppo, Realme and Samsung, which stop background apps.
